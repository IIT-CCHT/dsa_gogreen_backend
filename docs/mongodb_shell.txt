Queries
-----------------------------------

  Operatore di confronto:
  mydb> db.users.find({ age: {$gt:18} })
  mydb> db.users.find({ age: {$gt:18}, first_name: "Luca" })
  $eq: Uguale a
  $ne: Diverso da
  $gt: Maggiore di
  $lt: Minore di
  $gte: Maggiore o uguale a
  $lte: Minore o uguale a

  Operatore di confronto logico:
  mydb> db.users.find({ $or: [ {first_name: "luca"}, {age: {$gte: 18} } ] })
  $and: Logica AND
  $or: Logica OR
  $not: Logica NOT
  $nor: Logica NOR

  Operatore di esistenza:
  $exists: Verifica se un campo esiste in un documento

  Operatore di tipo:
  $type: Verifica il tipo di un campo

  Operatore di regex:
  $regex: Ricerca basata su espressioni regolari

  Operatore di elementi in un array:
  mydb> db.users.find({ age: {$in: [18,19,20] } })
  mydb> db.users.find({ $or: [{ age:18 }, {age:19}, {age:20}] }) <--- equivalent to the one above
  mydb> db.users.find({ sports: "tennis"}) <--- Filter array fields
  mydb> db.users.find({ sports: ["tennis"]}) <--- Filter array fields only exact array
  mydb> db.users.find({ sports: {$all: ["tennis","golf"] } }) <---- Filter array fields list inside array
  mydb> db.users.find({ sports: {$all: ["tennis","golf"] } }) <--- Filter array fields list inside array
  mydb> db.users.find({ "jobs.name": "musician" }) <--- Filter array of object
  $in: Corrispondenza con uno qualsiasi dei valori specificati
  $nin: Non corrispondenza con nessuno dei valori specificati
  $all: Corrispondenza con tutti i valori specificati

  Operatore di dimensione dell'array:
  $size: Verifica la dimensione di un array

  Operatore di elemMatch:
  $elemMatch: Ricerca elementi in un array che soddisfano tutti i criteri specificati

  Operatore di proiezione:
  projection: Specifica i campi da includere o escludere nei risultati della query
